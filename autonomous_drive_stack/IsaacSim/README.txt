Someone can format this in markdown later. Open the Map.usda in IsaacSim and it should find the dependencies. Go to Window -> Script Editor, then File -> Open in the Script Editor. Find IsaacSim/BootCode/boot.py and hit Run, you should see "Boot ready." When you hit Play and Stop it will run those files automatically. Generally, put setup code that needs to run beforehand in the Stop file, and put code that runs at the start or during simulation in the Start file. Your camera will also change between the default Perspective one and MilaCamera during run time vs in editor.
