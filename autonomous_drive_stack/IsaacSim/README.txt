Someone can format this in markdown later. Open the Map.usda in IsaacSim and it should find the dependencies. Go to Window -> Script Editor, then File -> Open in the Script Editor. Find IsaacSim/BootCode/boot.py and hit Run, you should see "Boot ready." When you hit Play and Stop it will run those files automatically. You only need to run it once per Isaac Sim launch. Generally, put setup code that needs to run beforehand in the Stop file, and put code that runs at the start or during simulation in the Start file. I'd recommend checking out the snippets in the Script Editor, it's got some cool stuff. This setup is designed to be used with a code editor like Visual Studio Code, just make your changes to start and stop, hit control s, and then play in Isaac Sim. Your camera will also change between the default Perspective one and MilaCamera during run time vs in editor.
